# Paralingo Books

Free original-language classics prepared for the
[Paralingo](https://github.com/Paralingo) reading app.

## Published books

| Language | Book | Author | Level | Download |
| --- | --- | --- | --- | --- |
| Spanish | *Marianela* | Benito Pérez Galdós | Starter classic | [EPUB](https://github.com/Paralingo/paralingo-books/releases/download/marianela-v1.0.0/paralingo-es-marianela-v1.epub) |

“Starter classic” means this is the first and most approachable Paralingo
selection for the language. It does not mean the historical text is suitable
for an A1 or A2 learner.

## Repository layout

- `book-catalog-v1.json` is the versioned catalogue consumed by the app.
- `rights/` contains a public evidence record for every downloadable edition.
- `assets/` contains Paralingo-owned cover art and its provenance.
- `build/` contains reproducible edition-building scripts.
- GitHub Releases contain the downloadable EPUB files.

## Rights policy

Paralingo editions use original-language works selected under a conservative
rights policy. Modern translations, introductions, annotations, inherited
covers, fonts, and illustrations are excluded unless separately cleared.

The underlying text and the Paralingo cover/layout may have different rights.
See the individual rights record before redistributing an edition. Public
availability on GitHub is not itself a declaration that every component is in
the public domain in every jurisdiction.

Project Gutenberg is credited as a digitization source. Paralingo does not use
Project Gutenberg branding and does not use Project Gutenberg as its download
server.
